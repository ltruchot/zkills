# Security policy

## Report

- Private report: GitHub Security Advisories on this repo, "Report a vulnerability"
- No public issue for exploitable bug
- Acknowledgment within 7 days, fix or plan within 30 days

## Scope

- CLI code in `packages/zkills/src`, published `dist/cli.js`
- Threat model: [docs/threat-model.md](docs/threat-model.md)
- Out of scope: Claude Code runtime, skill content authored in banks

## Supported versions

- Latest minor only, fix ships as patch release
