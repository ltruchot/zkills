# Philosophy

## Deterministic over prompted

- Hashes, diffs and merges, no AI in the install loop
- Same lock + same bank = same files, every machine

## Active participation

- Preview before write, confirm before apply
- Diff shown, not hidden, so humans keep reading skills

## Small and scoped

- Skills under 500 lines, files under 50
- Few curated skills per project beat many generic ones
- `list` shows what loads into context

## Portable by default

- Skills stay spec-compliant plain files
- No lock-in to zkills: delete lock, files remain

## Org scale

- Bank is a registry: review, pin, audit
- Placeholders replace fork-and-drift
- Exit codes make CI the enforcer
